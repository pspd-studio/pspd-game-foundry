# PSPD GAME FOUNDRY

게임을 만드는 저장소가 아니라 **게임을 통과시키거나 죽이는 공정**이다.
개별 게임은 화물이고, 이 공정이 상품이다. 재미·수익성이 없다고 판정되면
게임은 게이트에서 죽고, 공정과 배운 것은 다음 게임으로 넘어간다.

## 게이트

| 게이트 | 스킬 | 비용 상한 | 산출물 |
|---|---|---|---|
| G1 기획 | `game-brief` | 반나절 | 한 장 기획서 + SSOT 초안 |
| G2 모델 | `game-model` | 며칠 | 데이터 스키마 + 시뮬레이터 + 지표 |
| G3 슬라이스 | `game-slice` | 몇 주 | 텍스트 수직 슬라이스(웹) + 사람 플레이 지표 |
| 판정 | `game-gate` | 즉시 | 통과 / 보류 / 킬 + 킬이면 부검 한 장 |

원칙: **G3 통과 전에는 아트에 1원도 쓰지 않는다.**

## 구조

```
docs/pipeline.md   게이트별 통과·킬 기준 (숫자)
template/          새 게임 시작용 뼈대. game-brief가 games/<id>/로 복제한다
games/<id>/        게임 인스턴스. 킬돼도 지우지 않고 STATUS만 KILLED로 바꾼다
skills/            스킬 원본 4종
```
