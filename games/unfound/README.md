# UNFOUND

전투 중 쏟아지는 재료 카드를 자유롭게 조합해 예상 밖의 결과를 발견하고,
그 결과의 전투 효과로 위에서 내려오는 적을 처리하는 싱글플레이 로그라이크.

PC / 스팀 우선 · 웹(TypeScript) 기반 · 1인 개발

---

## 5초 요약

이 저장소는 **게임보다 파이프라인이 먼저** 만들어져 있다.
사람은 결정만 하고, 설계·검증·구현은 `.claude/agents/`의 에이전트 넷이 나눠 맡는다.

## 지금 바로 해볼 것

```bash
node tools/validate.mjs          # 데이터 무결성 + 레시피 그래프 건강도
node tools/simulate.mjs 2000 42  # 2000판 자동 플레이
node tools/smoke.mjs             # 한 판이 끝까지 도는지 (승/패 둘 다) + 렌더 단위 확인
```

검증기·시뮬레이터는 의존성이 없다. 브라우저로 실제 플레이하려면 Vite가 필요하다.

```bash
npm install
npm run dev      # http://localhost:5173 — 로컬 플레이
npm run build    # dist/ 에 정적 파일 (Vercel 배포 대상)
npm run check    # validate + 2000판 시뮬 + 스모크
```

Node는 22.18 이상. `tools/*.mjs`가 `src/core/*.ts`를 그대로 import하므로
(노드 내장 타입 제거) 검증에 빌드 단계가 필요 없다.

## 폴더

```
docs/       기획. 00-SSOT.md 가 규칙의 유일한 기준
data/       카드·레시피·적·지역·밸런스 수치 (전부 JSON, 코드에 하드코딩 금지)
src/core/   전투 코어. 순수 함수, UI 없음. 시뮬레이터와 브라우저가 공유한다
src/ui/     화면. DOM/CSS. 규칙 판단을 하지 않고 코어에 물어본다
tools/      검증기 · 시뮬레이터 · 스모크 테스트
.claude/    에이전트 정의 4종
assets/     에셋 출처·라이선스 대장
```

## 에이전트

| 이름 | 부를 때 | 하는 일 |
|---|---|---|
| `recipe-designer` | "레시피 뽑아줘" | 4중 제약을 통과한 조합만 만든다 |
| `balance-analyst` | "밸런스 봐줘" | 값 하나씩 바꿔가며 수천 판 돌린다 |
| `builder` | "구현해줘" | JSON을 읽어 도는 게임을 만든다 |
| `playtest-analyst` | "로그 봐줘" | 사람이 실제로 시도한 조합을 캐낸다 |

모든 에이전트는 **결과물 + 결정 요청 3개 이하**로만 보고한다.
