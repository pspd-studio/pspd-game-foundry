# UNFOUND v2.1 — 피벗 기획서 (7인 라운드테이블 반영판)

작성: 2026-08-09 · v2.0에서 라운드테이블(`02-roundtable-2026-08-09.md`) 채택안 반영 · 승인 대기
승인 시 이 문서가 SSOT 대개정의 원본이 된다.

## v2.0 → v2.1 변경 요약

1. 계약(주문서) 미확정 → **코어 승격**. 런 실패 = 계약 2/3 미달로 정의 (실패 조건 신설)
2. 첫 발견 프리미엄 + 도감 미확정 → **코어 승격** (배수 ×2/×2.5/×4)
3. 인력·파견·유지비 → **G4 이연** (탐험가 부활 1순위). 압박은 마감+포화+계약으로 재편
4. 메타 해금 전체 → **G4 이연**. 원칙만 확정: "해금은 파워가 아니라 공간"
5. 턴제 배타성 신설: 시장 행동 턴당 1회, 공급 드래프트, 계약 중간 마감
6. 브루트포스 방어 신설: 미발견 시도 상한(공급×2) + 정보 경제(계열 태그·근접 신호·단서 판매)
7. 온보딩 확정: 턴 1~3 push 공급 → 첫 판매(구매자 방문) 후 시장 개방
8. 유니크 변동성 4분포 → G3는 성공/실패 2분포로 축소

## 한 줄 정의

숨겨진 레시피를 조합으로 발견하고, 발견물을 시장에 팔아 번 돈으로 더 깊은 조합을
조달해 계약 마감을 넘기는 **턴제 조합-경제 로그라이크**.

스토어 한 줄 (클론헌터 채택안): **"아무도 레시피를 모른다. 그래서 비싸다."**
포지션: 스택랜드 대체재가 아니라 "스택랜드를 끝낸 사람의 다음 게임".

## 핵심 감정

- "이 둘을 합치면 뭐가 나오지?" (발견 호기심)
- "첫 발견은 비싸게 사준다. 긁기 전에 머리를 쓰자" (추론의 현금 보상)
- "빵값이 물렸다. 다른 계통을 열어야 한다" (포화가 떠미는 실험)
- "중간 마감 2턴 전, 이 조합이면 계약이 채워진다 — 지른다" (마감 앞 도박)

## 핵심 루프 (v2.1)

```
[턴 시작] 공급 드래프트: 후보 3장 중 1장 선택 (턴 1~3은 push 3장)
    ↓
[조합] 필드 7칸에서 2장 병합 (미발견 시도는 턴당 공급×2회까지)
    ↓
[발견] 신규 카드 → 도감 등재 + 첫 판매 프리미엄 / 실패 → 근접 신호로 단서
    ↓
[시장] 턴당 1회: 판매 (수요 게시판 소등, 팔수록 하락) or 구매 (재료·단서 조달)
    ↓
[계약 판정] 중간 마감(10턴) · 최종 마감(20~22턴) — 계약 2/3 미달이면 런 실패
    ↓
[정산] 성공 런 100% / 실패 런 ≤50% → (G4: 메타 해금) → 다음 런
```

## 압박 설계 (전투의 대체물, v2.1 확정)

1. **계약 마감** — 유일한 강제 실패 조건. 런당 계약: 첫 런 1건 → 이후 3건 (초반·중간·최종 정산).
   목표 실패율: 무해금 30~50% → 회차 진행으로 15~25% 수렴. **실패 런의 정산 재화 ≤ 성공 런의 50%** (이 이빨이 없으면 실패율은 분식회계).
2. **시장 포화** — 상품 단위가 아니라 **티어(카테고리) 수요 풀** 단위. 예: tier B 총수요 8유닛/런,
   초과분부터 r^k 감쇠 (r 초기값 0.85, 런 내 회복 없음). 아는 상품 회전으로 회피 불가.
   UI는 "수요 게시판 ▢▢▢▢▢▢▢▢ — 팔 때마다 즉시 소등"으로 물리적 사건화.
3. **필드 7칸 + 슬롯 비용** — v1에서 계승하되 **재측정** (push→pull 전환으로 점유율 체계가 바뀜.
   "검증된 자산"이 아니라 "계승하는 도구 + 재검증할 가설").

유지비·파산 축은 인력과 함께 G4로. G3의 실패는 전부 계약이 만든다.

## 턴제 배타성 (신설 — "포기 없는 턴제는 처리다")

- **시장 행동 턴당 1회**: 구매 or 판매 택1 (스플렌더 문법). 차익거래 구조 차단 겸용.
- **공급 드래프트**: 후보 3장 중 1장, 나머지 소멸. 매 턴의 첫 결정. v1 "지역 풀에서 재료가 못 만나는" 문제도 완화.
- **계약 중간 마감**: 시간의 파동. 계약 JSON에 마감 턴 필드.
- 조합 자체는 무료 유지 (v1 턴당 조합 1.11 체계 보존).
- 미가공 재판매가 = 매입가 × 0.5 (차익거래 프린터 차단, 규칙 명시).

## 발견 시스템 (v2.1 확정)

- **레시피 2장 고정** (v1 SSOT 재확정 유지). 첫 발견 프리미엄: tier A ×2.0 / B ×2.5 / C ×4.0 (상한 ×4 — 초과 시 저티어 파밍이 지배 전략화).
- **브루트포스 방어**: 턴당 미발견 조합 시도 상한 = 공급 장수 × 2 (기본 6회). 도감 등재 레시피 실행은 무제한. 실험은 공짜, 전수 스캔은 4턴짜리 투자.
- **정보 경제** (위키 대응 1순위): ① 원소 계열 태그 — 계열 규칙성이 후보 21쌍을 3쌍으로 줄인다.
  ② 실패 근접 신호 — "아무 일도 없었다" vs "부글거리다 멎었다"를 구분. 실패도 추론 재료.
  ③ 단서 판매 — 상점에서 부분 힌트 구매 ("재료 A는 액체 계열과 반응이 좋다"). 위키보다 게임 안 단서가 싸고 재밌게.
- **유니크(고티어) 조합**: G3는 성공/실패 2분포, 실패 시 재료 유지. 열화·강화 축은 열화방지 메타와 세트로 G4.
- **조건부 레시피** (`conditions` 스키마): 제1 재플레이 방어선. 조건 셔플(촉매·장소를 런마다 재배치)로 위키 표 완성을 지연. G3 데이터 확인 후 점화.
- **tier C 한정 재료 재추첨** (Noita식, 카테고리 내): G4 보류. 단서 시스템 성립 + 시드별 성립 검증기 전제.

## 온보딩 (첫 60초 — G3 지표 직결, 신설)

1. 시작 필드 7장, 그중 **확정 조합 2쌍 이상 보장** (시드 보정). 첫 조합까지의 장벽은 드래그 한 번.
2. 턴 1~3: v1 그대로 무료 push 공급 3장. **시장은 잠금.**
3. 첫 발견물에 **구매자가 찾아온다** ("N골드에 삽니다" 카드) — 판매 동사를 화면이 시연. 이후 시장 개방, pull 전환.
4. 계약은 턴 1부터 필드 옆 오브젝트로 상시 노출 (빈 칸 + 줄어드는 게이지 + 보상 동전).
5. 마감은 "턴 8/12" 숫자가 아니라 **줄어드는 트랙**. 돈의 증감은 전부 물리 연출 (판매 직후 가격표가 그 자리에서 깎임).
6. 위험 조합(유니크)은 사전 고지 배지 + 확인 단계, 확정 조합은 즉시 실행 — 비대칭이 tier를 무언으로 가르침.
7. 실패 조합에 소리/흔들림 피드백 ("안 되는 조합" vs "드래그 미스" 구분).
8. 정산 화면은 엔딩이 아니라 광고판: 못 채운 도감 실루엣 + (G4) 잠긴 해금 목록.
9. G3 로그에 마찰 계측 내장: 첫 조합·첫 판매·첫 구매·첫 턴종료 도달 시각, 무반응 클릭 수, 동일 실패쌍 반복 횟수.

## 화면 문법 (클론 인상 방어 — 아트가 아니라 UI 오브젝트로)

레퍼런스는 스택랜드가 아니라 Potion Craft·Strange Horticulture (지물 중심 화면).
전면에 세울 오브젝트: **7칸 슬롯 그리드**(자유 배치가 아니라는 선언) · **물음표 뚫린 도감** ·
**시세가 꺾이는 수요 게시판** · **인장 찍힌 계약서**. "카드 게임"이 아니라 "카드로 하는 상점 경영"으로 보이게.
캡슐: 물음표 절반 뚫린 도감 페이지 + 치솟았다 꺾이는 시세 화살표.

## G3 슬라이스 확정 목록 (11개 — 이 밖의 것은 넣지 않는다)

1. v1 조합 코어 (2장 병합, 7칸, 슬롯 비용, 버리기 1장, 지역 풀)
2. 공급: 턴 1~3 push → 이후 드래프트 (3장 중 1택)
3. 고정 마감 N=20~22턴 + 계약 중간 마감 (10턴)
4. 티어 수요 풀 포화 (계단식, r=0.85) + 수요 게시판 UI
5. 시장 행동 턴당 1회 (구매 or 판매)
6. 첫 발견 프리미엄 (×2/×2.5/×4) + 런 내 도감
7. 고정 계약 3~5종 JSON (첫 런 1건 → 이후 3건), 실패 정산 ≤50%
8. 카드 단품 구매 (첫 판매 후 개방)
9. 유니크 성공/실패 2분포 (재료 유지)
10. 미발견 시도 상한 (공급 × 2)
11. 정보 경제 최소판 (계열 태그 + 실패 근접 신호 + 상점 단서 1종)

전부 텍스트/도형. **G4 백로그** (승격 순위순): 탐험가(미지 카드 반입) → 메타 해금(원칙: 공간 8할, 열화방지는 −20/−35/−50% 상한부 경감, 완전보호는 런 내 소모품 부적만) → 인력 시스템(슬롯 점유+상한 3명+파견 중 잠금 — G3에서 "버튼 엑셀" 반응 시 1순위 재소환) → 열화/강화 4분포 → 팩 구매 → tier C 재료 재추첨 → 조건부 레시피 점화.

## 차별점 · 수익 가설 (v2.0 유지 + 보강)

스택랜드와 달리 레시피가 숨겨진 발견 대상이고(스택랜드는 아이디어 카드로 공개), 실시간 방치가 아니라
**포기가 있는 턴제 런**이다. 카이로소프트 문법(경제 루프·궁합 발견·정산 리듬)의 "미친 듯이 재밌는
처음 2시간"을 런 단위로 재생산하되, 카이로의 3대 유전병(방치 쾌감·파산 불가·해금 카탈로그)은 이식 금지.
PC/스팀 $5.99~7.99. 타겟: 스택랜드·Little Alchemy·Infinite Craft를 좋아하지만 "레시피를 다 알려줘서
아쉬웠던" 플레이어 + 카이로소프트 팬.

## 1인 제작 적합성 (라운드테이블 재감사 반영)

- G3 슬라이스 11개 중 신규 6개, 신규 중 난이도 '중' 이상 0개 (프로듀서 감사 통과 기준).
- 아트: 텍스트/도형 (G3) → 단순 아이콘 스타일 (G4). 고품질 일러스트 필요 오브젝트 10개 미만.
- v1 재사용: simulate.mjs (턴 루프·2000판 하니스 — 전투 모듈 적출, 시장·계약 모듈 이식),
  validate.mjs (지역 도달성 검사 유효), rules.json 손잡이, recipes.json 스키마, 카드 32장/레시피 50개,
  그리고 실측 지식 3건 (풀 확장은 레시피를 죽인다 / 병목은 필드 막힘 / 점유율 94%는 막힘).

## G2 재진입 킬 라인 (3회 시도로 못 잡으면 피벗 폐기)

| 지표 | AI | 기준 |
|---|---|---|
| 런 실패율 (계약 2/3 미달) | 추론 | 30~50% (무해금), 해금 모사 시 15~25%로 단조 감소 |
| 계약 달성률 | 선지식 (레시피 5개 알고 시작, 발견 안 함) | **< 40%** — 아는 레시피 회전으로 못 이겨야 함 |
| 첫 tier C 도달 속도 | 단서 활용 vs 전수 스캔 | 단서 쪽이 **30% 이상 빠름** — 추론에 보상 |

보조: 턴당 조합 ≥1.0 · 점유율 65~80% (재측정) · 판당 발견 ≥7.8종 · **턴당 행동 포기 수 ≥1.0** ·
무개입 턴 비율 상한 · 마지막 3턴 조합 ≥0.7 · 자산 곡선 비폭주 (후반 ≤ 초반×1.5) · 최다 상품 매출 <40% ·
포화 ON/OFF 발견 격차 ≥2종 · 첫 판매 ≤3턴 · 미사용 레시피 <30% · **도감 100% AI 달성률 20~90%**
(포스트 발견 게임 성립 — 이 게임의 가격 정당성은 레시피 개수가 아니라 여기 걸려 있다).
