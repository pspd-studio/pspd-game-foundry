# <게임명> — 세션 공통 지침

이 폴더는 PSPD GAME FOUNDRY의 게임 인스턴스다. 파운드리 공통 규칙(`../../docs/pipeline.md`)이 상위 기준이다.

## 역할 분담

사람(PSPD)은 기획과 결정만 한다. 결정 요청은 한 번에 **3개 이하**.
넘칠 것 같으면 기본값으로 처리하고 그렇게 했다고 한 줄 적는다.

## 무엇이 진실인가

1. `STATUS.md` — 현재 게이트와 상태
2. `docs/00-SSOT.md` — 규칙의 유일한 기준. 충돌 시 이 파일이 이긴다
3. `data/*.json` — 콘텐츠·수치의 유일한 기준

규칙 변경 → SSOT 갱신. 수치 변경 → `rules.json` changelog에 이유. 예외 없음.

## 금지

- 콘텐츠·수치를 코드에 하드코딩
- SSOT 미확정 항목을 임의 확정 (스위치로 두고 결정 요청)
- G3 통과 전 아트 제작
- 검증(`node tools/validate.mjs`) 없이 작업 종료

## 에이전트 분담

| 에이전트 | 담당 |
|---|---|
| `content-designer` | 콘텐츠 설계 (게임의 핵심 콘텐츠 단위) |
| `balance-analyst` | 시뮬레이션·수치 튜닝 |
| `builder` | 코드 구현 |
| `playtest-analyst` | 사람 플레이 로그 분석 |
